# Snake Game

A simple Snake Game built using **HTML, CSS, and JavaScript** as a project to revise and practice JavaScript concepts.

## Features

* Snake movement using arrow keys
* Random food generation
* Score tracking
* High score using `localStorage`
* Snake self-collision detection
* Wall collision detection
* Game timer
* Restart functionality
* Game-over modal with transition

## Technologies Used

* HTML
* CSS
* JavaScript

## Controls

* ⬆️ Up Arrow — Move Up
* ⬇️ Down Arrow — Move Down
* ⬅️ Left Arrow — Move Left
* ➡️ Right Arrow — Move Right

## JavaScript Concepts Used

* DOM Manipulation
* Event Listeners
* Arrays & Objects
* Functions
* `setInterval()`
* `localStorage`
* Keyboard Events
* Conditional Statements
* Loops

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
